Connect Any Ebook Reader to Opus Library

Opus Library exposes standard OPDS 1.2, OPDS 2.0, W3C EPUB 3.3 / Web Publication Manifest, and REST JSON endpoints so any compatible reader app or client can browse, pull, and read books with word-by-word audio synchronization.

Catalog & Standards Endpoints

StandardEndpointContent-TypeCompatible Readers
OPDS 1.2 /opds.xml application/atom+xml;profile=opds-catalog;kind=acquisition KOReader, Calibre, PocketBook, Cantook, Moon+ Reader
OPDS 2.0 /opds.json application/opds+json Thorium Reader, Readium-based apps
W3C / RWPM /api/w3c/{slug}/manifest.json application/webpub+json Readium Web, W3C EPUB 3.3 / WebPub clients
Static Catalog /catalog.json application/json Custom web clients & scripts
OpenAPI 3.0 /openapi.json application/json Swagger / OpenAPI codegen

REST API Endpoints (Cloudflare Pages Functions + D1)

Method & PathAuthDescription
GET /api/booksPublic / CookieList all public books (plus owner's private drafts when signed in).
POST /api/booksCookieCreate a new book from title, author, and raw .txt/.md text.
GET /api/books/{slug}Public / OwnerFetch full book JSON (chapters, segments, word timestamps, audio URLs).
PUT /api/books/{slug}OwnerSave updated Cast, Emotion, Rate/Pitch/Volume, Ambiance & SFX edits to D1.
POST /api/books/{slug}/renderOwnerQueue an audio & EPUB3 render job in D1 render_jobs.
POST /api/auth/register / loginPublicCreate account or sign in (sets HttpOnly session cookie).

How to Subscribe in Ebook Readers

  • Thorium Reader / KOReader / Calibre / Cantook: Add OPDS catalog URL https://read.opuslibrary.com/opds.xml (or /opds.json for OPDS 2.0).
  • Apple Books (macOS / iOS): Apple Books does not subscribe to OPDS feeds; download the .epub directly from the Library card or the http://opds-spec.org/acquisition link (EPUB 3.3 Fixed-Layout with SMIL Media Overlays, W3C EPUBCheck 0 errors).
curl -s https://read.opuslibrary.com/opds.json | head -n 25

Automated Test Protocol (For AI Agents & CI)

Any client or AI agent integrating with Opus Library should verify these 4 protocol stages:

  1. OPDS 1.2 / 2.0 & OpenSearch: GET /opds.xml (200 Atom XML), GET /opensearch.xml (200), GET /api/opds.json?q=alice (200, 1 match).
  2. W3C Manifest + Book JSON + Audio: GET /api/w3c/{slug}/manifest.json (200 application/webpub+json), GET /api/books/{slug} (200), HEAD /books/{slug}/audio/ch01.m4a (200).
  3. CORS & Error Guard: OPTIONS /api/books (204, Access-Control-Allow-Origin: *), malformed JSON to POST /api/auth/login (400).
  4. Auth + Private Book CRUD + Cleanup: Register (201) → Create isPublic: false (201) → Get (200, canEdit: true) → Put (200) → Queue Render (202) → Delete (200) → Get (404) → Logout (200).
curl -sf https://read.opuslibrary.com/llms.txt | tail -n 25
